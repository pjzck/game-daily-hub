# Project instructions

- This is the exploration stage of a Windows desktop app planned for Tauri 2, React, TypeScript and Rust. Keep implemented features distinct from proposals.
- The GitHub owner is the personal account `pjzck`. Verify the identity and remote before publishing; do not move this project to an organization or another account.
- Do not add GitHub Actions workflows or configure Actions. Run checks locally with `npm run check` and parse changed PowerShell scripts locally.
- Keep machine paths, instance names, ADB addresses and discovery output in ignored `.local/` files. Public examples use placeholders.
- Never commit credentials, browser cookies, account databases or raw game/tool logs. Preserve external project license boundaries.
- Discovery does not authorize executing game tasks. Verify the requested account, device and preset before task execution; never equate process exit with completed daily objectives.
