## 1. 最小接入验证

- 选一个已明确绑定游戏的 MuMu 实例。
- 验证 MAA / M9A 当前版本的外部启动、停止和完成状态来源。
- 对一个社区数据源完成主动登录、角色选择和只读查询。
- 记录版本约束、数据字段、失效行为和凭据保存方式。

验收：有可复现步骤和实际结果；失败或未验证的能力不能以成功状态展示。真实执行游戏任务前明确选择目标账号与预设。

## 2. Tauri 基础应用

- 准备 Rust / Windows 构建环境。
- 建立 Tauri 2 + React + TypeScript 项目和 SQLite 数据模型。
- 实现账号资料、五款游戏入口、安装选择、MuMu 实例关联。
- 展示首个已验证的数据源及更新时间，提供人工待办。

验收：Windows 能安装、启动、保存设置和重新打开；账号关联及未知状态准确。

## 3. MAA / M9A 每日执行

- 实现独立的执行适配器与事件归一化。
- 支持单实例串行、多实例分别执行、停止、超时和有限重试。
- 提供按次运行的结果、配置快照、日志和人工处理状态。

验收：指定实例能执行指定预设；成功、失败、取消与未知状态可区分，恢复程序不重复执行已完成事项。

## 4. 完整日常总览

- 完成原神 / 崩铁数据适配；鸣潮通过协议验证后接入。
- 增加回满提醒、每日 / 每周边界、托盘和睡眠恢复处理。
- 处理凭据失效、上游限流、旧数据展示和配置迁移。

验收：数据源部分失败时，其余账号仍可使用；提醒不把推算当作实时数据；日志与导出不泄漏凭据。
